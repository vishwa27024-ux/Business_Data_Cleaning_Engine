
# 📊 Business Data Cleaning Engine

A Python-based data cleaning and business spreadsheet automation project built with Pandas.

The goal is to transform messy spreadsheet data into cleaner, more consistent Excel outputs that are easier to use for business reporting and analysis.

## 🚀 Features

- Clean and organize spreadsheet data.
- Detect and remove duplicate records.
- Standardize date formats.
- Process business data using Python and Pandas.
- Export cleaned data into Excel files.
- Reduce repetitive manual spreadsheet-cleaning work.

## 🧰 Tech Stack

- **Language:** Python
- **Data processing:** Pandas
- **Input and output:** Excel spreadsheets

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vishwa27024-ux/Business_Data_Cleaning_Engine.git
```

### 2. Open the project directory

```bash
cd Business_Data_Cleaning_Engine
```

### 3. Create a virtual environment (recommended)

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

On macOS or Linux:

```bash
source .venv/bin/activate
```

### 4. Install dependencies

```bash
python -m pip install pandas openpyxl
```

### 5. Run the script

```bash
python business_data_cleaner.py
```

**Note:** Ensure your input Excel files are placed in the locations expected by the script. Update file paths if necessary.

## 🎯 Why This Project?

Businesses often spend time fixing inconsistent spreadsheet data before it can be used for reporting. This project explores how Python automation can make that process more repeatable and efficient.
